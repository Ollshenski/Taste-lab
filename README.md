# Taste Lab — ონლაინ მაღაზია

სუბლიმირებული იოგურტისა და ხილის სნექების ინტერაქციული ონლაინ მაღაზია მართვის პანელით.

## გაშვება

საჭიროა Node.js 18+.

```bash
npm install
npm start
```

- საიტი: http://localhost:3000
- მართვის პანელი: http://localhost:3000/admin
- საწყისი პაროლი: `tastelab2026` (ან `ADMIN_PASSWORD` გარემოს ცვლადი). **პირველი შესვლისთანავე შეცვალეთ** პანელის „პაროლი“ გვერდზე.

## რა არის საიტზე

- **Hero** — ინტერაქციული კოლბა, მცურავი ხილი (დააჭირე — „ხრაშ!“), მაუსის პარალაქსი
- **მაღაზია** — ფილტრები, 3D ბარათები, პროდუქტის დეტალური ფანჯარა, „კალათაში გაფრენის“ ანიმაცია
- **ლაბორატორია** — სუბლიმაციის 4 ეტაპი თერმომეტრით, რომელიც სქროლზე იცვლება
- **Lab Mix** — მენდელეევის ცხრილის სტილის კონსტრუქტორი: აირჩიე 2–4 გემო, კოლბა ივსება და ყიდულობ შენს მიქსს
- **სლაიდერი „წყალი მიდის, გემო რჩება“**, შეფასებები, FAQ, გამოწერა
- **კალათა** — უფასო მიწოდების პროგრესის ზოლით; **Checkout** — შეკვეთის გაფორმება

## მართვის პანელი

დაშბორდი (შემოსავალი, გრაფიკი, მარაგი) · შეკვეთები (სტატუსები, ძებნა, CSV) · პროდუქტები (დამატება/რედაქტირება, ფოტოს ატვირთვა, ფასდაკლება, მარაგი, თანმიმდევრობა, დამალვა) · საიტის ყველა ტექსტი · მიწოდების ფასი და კონტაქტები · გამომწერები · პაროლი

## ონლაინ გადახდა (Flitt)

ინტეგრაცია: `lib/payments.js`. მომხმარებელი გადადის Flitt-ის გადახდის გვერდზე, შედეგს Flitt აგზავნის ორჯერ
(სერვერზე `/api/payments/callback` და მომხმარებლის ბრაუზერით `/payment/return`), ორივე ხელმოწერით მოწმდება.

- გადახდილი → შეკვეთა „გადახდილი“
- უარყოფილი/ვადაგასული → შეკვეთა უქმდება, მარაგი ბრუნდება, მომხმარებელს კალათა რჩება
- თანხა თუ არ ემთხვევა შეკვეთას → შეკვეთა არ მოინიშნება გადახდილად და ადმინში ჩნდება გაფრთხილება

ჩართვა: სერვერზე დააყენეთ `FLITT_MERCHANT_ID`, `FLITT_SECRET_KEY`, `PUBLIC_URL`, შემდეგ ადმინში
„პარამეტრები → ონლაინ გადახდა ბარათით“. სანამ ცვლადები არ არის, ბარათით გადახდა საიტზე არ ჩანს.

დამატებით: სერვერი ყოველ 5 წუთში Flitt-ის სტატუსის API-ით ამოწმებს მოლოდინში მყოფ ბარათით შეკვეთებს
(დაკარგული callback-ის ან მიტოვებული გადახდის შემთხვევისთვის). გადაუხდელი შეკვეთა Flitt-ში 1 საათში იწურება,
რის შემდეგაც ავტომატურად უქმდება და მარაგი ბრუნდება. ადმინში შეკვეთაზე არის ღილაკი „გადახდის შემოწმება Flitt-ში“.

Flitt-ის callback-ები მოდის IP-ებიდან `54.154.216.60`, `3.75.125.89` — თუ სერვერზე firewall გაქვთ, დაუშვით.

## შეკვეთის წერილები

`lib/mailer.js`. ყოველ შეკვეთაზე იგზავნება ორი წერილი: მაღაზიას (`ORDER_NOTIFY_TO`) — შეკვეთის დეტალებით,
და მომხმარებელს — დადასტურება მის ენაზე (თუ ელ-ფოსტა მიუთითა). ნაღდით გადახდისას — მაშინვე, ბარათით —
მხოლოდ Flitt-ის მიერ გადახდის დადასტურების შემდეგ. თითო შეკვეთაზე წერილები ერთხელ იგზავნება.

ჩართვა: `.env`-ში `SMTP_HOST`, `SMTP_PORT=587`, `SMTP_USER`, `SMTP_PASS` (იხ. `.env.example`), შემდეგ
ადმინში „პარამეტრები → ელფოსტის შეტყობინებები → სატესტო წერილის გაგზავნა“. Hetzner ბლოკავს 25 და 465 პორტებს,
ამიტომ გამოიყენეთ 587.

თუ წერილები არ მოდის, სერვერზე გაუშვით დიაგნოსტიკა (პაროლს არ აჩვენებს):

```bash
docker compose exec app node scripts/check-mail.js --send
```

ის ამოწმებს `.env`-ს, კავშირს Zoho-სთან, ლოგინს და აგზავნის სატესტო წერილს. Zoho-ზე საკუთარი დომენის
ფოსტისთვის ხშირად საჭიროა `SMTP_HOST=smtppro.zoho.eu` — დიაგნოსტიკა ორივე ვარიანტს ცდის.

## პროდაქშენზე გაშვება (VPS + Docker)

საჭიროა Linux სერვერი (Ubuntu, 1–2 GB RAM) Docker-ით და დომენის DNS:
`A` ჩანაწერი `@` და `www` → სერვერის IP.

```bash
git clone https://github.com/Ollshenski/Taste-lab.git && cd Taste-lab
```

```bash
cp .env.example .env && nano .env
```

```bash
docker compose up -d --build
```

Caddy ავტომატურად აიღებს HTTPS სერტიფიკატს დომენისთვის. ბაზა და ფოტოები ინახება Docker volume-ში `shop-data`
(ბექაპი: `docker compose cp app:/data ./backup`). განახლება: `git pull && docker compose up -d --build`.

Flitt-ის მერჩანტის პორტალში საიტის მისამართად მიუთითეთ თქვენი დომენი.

### DNS (Hetzner)

ზონა `taste-lab.ge` Hetzner-ის DNS-ზეა: `A` `@` და `www` → სერვერის IP, ფოსტა — Zoho (MX `mx.zoho.eu.` 10,
`mx2.zoho.eu.` 20, `mx3.zoho.eu.` 50, SPF `v=spf1 include:zohomail.eu ~all`, DKIM `zmail._domainkey`, `_dmarc`).

⚠️ Hetzner-ში MX/CNAME მნიშვნელობას ბოლოში **წერტილი** სჭირდება (`mx.zoho.eu.`), თორემ ის დომენის
ფარდობით მისამართად იქცევა (`mx.zoho.eu.taste-lab.ge`) და შემომავალი ფოსტა ჩერდება.
